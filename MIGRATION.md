# MIGRATION.md — Tailwind CSS → Bootstrap 5 + Material Design 3

> **Mandate:** Founder directive — replace Tailwind CSS entirely with Bootstrap 5 + Material Design 3. Bootstrap loads first, then MD3, then custom Chada CSS. The goal is to avoid the "AI-generated site" look.
> **Stack:** Laravel 12 + Blade + Bootstrap 5 + Material Design 3 (Web Components) + Laravel Mix + jQuery
> **Repo:** `DGCodeIdeas/chada.digital`
> **Status:** Migration spec + config files ready. Blade view migration is the remaining work.
> **Supersedes:** All previous redesign specs (V1–V5, WAB replication, light theme).

---

## 1. Why This Migration?

### The Problem with Tailwind
Tailwind CSS produces a very recognizable visual signature:
- `rounded-2xl`, `bg-background`, `text-muted-foreground`, `backdrop-blur-xl`
- Utility-first classes scattered across every HTML element
- Sites built with AI coding agents default to Tailwind because it's easy to generate
- The result looks identical to thousands of other AI-built sites

### Why Bootstrap + Material Design 3
| Framework | Role | Benefit |
|-----------|------|---------|
| **Bootstrap 5** | Foundation | Grid system, utilities, responsive breakpoints, standard components (navbar, cards, forms, buttons) |
| **Material Design 3** | Design language | Google's latest design system — color roles (primary, secondary, tertiary), elevation, motion, typography scale |
| **Custom SCSS** | Brand layer | Chada-specific overrides, custom components, unique visual identity |

**The combination produces a site that:**
- Uses standard Bootstrap class names (`container`, `row`, `col-md-6`, `card`, `btn-primary`)
- Gets Material Design's sophisticated color system and elevation
- Has custom SCSS that makes it visually distinct from any template
- Does NOT look like it was generated by an AI agent in 2024–2025

## 2. Architecture

### 2.1 Load Order (CSS)
```
1. Bootstrap 5 CSS (reboot + grid + utilities + components)
2. Material Design 3 tokens (color roles, elevation, shape, typography scale)
3. Bootstrap + MD3 component bridge (map Bootstrap components to MD3 tokens)
4. Custom Chada SCSS (brand colors, custom components, overrides)
```

### 2.2 Load Order (JS)
```
1. Bootstrap 5 JS (dropdowns, modals, tooltips, etc.)
2. Material Web Components (md-button, md-card, md-chip, etc.)
3. jQuery + custom modules (existing: toast, mobile-nav, contact-form, showcase-filters)
```

### 2.3 Design Token Mapping

| Tailwind Token (Old) | Bootstrap/MD3 Equivalent (New) | Value |
|----------------------|-------------------------------|-------|
| `bg-background` | `body` bg or `--md-sys-color-background` | `#f4f2ee` |
| `text-foreground` | `body` color or `--md-sys-color-on-background` | `#171717` |
| `bg-card` | `--md-sys-color-surface` or `.card` bg | `#fbfaf8` |
| `text-primary` | `--md-sys-color-primary` or `.text-primary` | `#2563eb` |
| `text-muted-foreground` | `--md-sys-color-on-surface-variant` or `.text-secondary` | `#525252` |
| `border-border` | `--md-sys-color-outline` or `.border` | `#e5e5e5` |
| `font-display` | Google Font: Outfit (headings) | Outfit |
| `font-sans` | Google Font: Inter (body) | Inter |
| `font-accent` | Google Font: Playfair Display (optional) | Playfair Display |
| `rounded-2xl` | Bootstrap: `.rounded-4` or MD3 shape tokens | `1rem` |
| `max-w-7xl` | Bootstrap: `.container` (max-width 1320px) | `1320px` |
| `px-6` | Bootstrap: `.px-4` (1.5rem) or `.px-3` (1rem) | varies |
| `py-20` | Bootstrap: `.py-5` (3rem) — custom spacing needed | custom |

## 3. File Changes

### 3.1 package.json

**Remove:**
- `tailwindcss`
- `postcss` (if only used for Tailwind)
- `autoprefixer` (Bootstrap includes its own)

**Add:**
- `bootstrap@^5.3.3`
- `@material/web@^2.0.0` (Material Design 3 Web Components)

### 3.2 webpack.mix.js

**Remove:** Tailwind from PostCSS pipeline.

**Add:** Bootstrap and MD3 entry points.

### 3.3 resources/sass/app.scss

**Remove:**
```scss
@tailwind base;
@tailwind components;
@tailwind utilities;
```

**Replace with:**
```scss
// 1. Bootstrap 5
@import "~bootstrap/scss/bootstrap";

// 2. Material Design 3 tokens
@import "md3-tokens";

// 3. Bootstrap + MD3 bridge
@import "md3-bootstrap-bridge";

// 4. Custom Chada
@import "chada-custom";
```

### 3.4 resources/js/app.js

**Add:**
```js
import 'bootstrap';
import '@material/web/all.js';
```

### 3.5 resources/views/layouts/app.blade.php

**Change:**
```blade
{{-- Old (Tailwind) --}}
<body class="bg-background text-foreground antialiased">

{{-- New (Bootstrap + MD3) --}}
<body class="mdc-typography">
```

### 3.6 resources/views/partials/fonts.blade.php

**Keep:** Google Fonts (Outfit, Inter, Playfair Display) — these are framework-agnostic.

## 4. Blade View Migration Guide

### 4.1 Layout → Bootstrap Grid

**Tailwind:**
```blade
<div class="mx-auto flex h-16 max-w-7xl items-center justify-between gap-6 px-6">
```

**Bootstrap + MD3:**
```blade
<div class="container d-flex align-items-center justify-content-between gap-3 py-2">
```

### 4.2 Cards → Bootstrap Cards + MD3 Elevation

**Tailwind:**
```blade
<div class="rounded-2xl border border-border bg-card/40 p-8">
```

**Bootstrap + MD3:**
```blade
<div class="card shadow-sm border-0 p-4" style="background-color: var(--md-sys-color-surface);">
```

### 4.3 Buttons → Bootstrap Buttons + MD3 Tokens

**Tailwind:**
```blade
<a class="inline-flex items-center justify-center rounded-full bg-primary px-6 py-3 text-sm font-medium text-white transition-colors hover:bg-primary/90">
```

**Bootstrap + MD3:**
```blade
<a class="btn btn-primary rounded-pill px-4 py-2">
```

With custom SCSS override:
```scss
.btn-primary {
  background-color: var(--md-sys-color-primary);
  border-color: var(--md-sys-color-primary);
  color: var(--md-sys-color-on-primary);
  text-transform: none;
  letter-spacing: 0;
  font-family: 'Inter', sans-serif;
}
```

### 4.4 Typography → Bootstrap + MD3 Scale

**Tailwind:**
```blade
<h1 class="font-display text-4xl font-bold leading-[1.1] tracking-tight md:text-5xl">
```

**Bootstrap + MD3:**
```blade
<h1 class="display-4 fw-bold" style="font-family: 'Outfit', sans-serif; line-height: 1.1;">
```

### 4.5 Spacing → Bootstrap Spacing Utilities

| Tailwind | Bootstrap | Value |
|----------|-----------|-------|
| `px-6` | `.px-4` | 1.5rem |
| `py-20` | `.py-5` | 3rem |
| `gap-6` | `.gap-3` | 1rem |
| `mt-6` | `.mt-4` | 1.5rem |
| `mb-5` | `.mb-3` | 1rem |
| `space-y-6` | `.vstack.gap-4` | 1.5rem gap |

**Note:** Bootstrap's spacing scale is 0.25rem-based (1 = 0.25rem, 2 = 0.5rem, 3 = 1rem, 4 = 1.5rem, 5 = 3rem). Tailwind's is 0.25rem-based too but with different defaults. Custom SCSS will bridge the gap for large spacing values (e.g., `py-20` = 5rem = custom class).

### 4.6 Colors → MD3 Color Roles

| Tailwind Class | MD3 Token | Bootstrap Override |
|----------------|-----------|-------------------|
| `bg-primary` | `--md-sys-color-primary` | `.bg-primary` |
| `text-primary` | `--md-sys-color-on-primary` | `.text-primary` |
| `bg-muted` | `--md-sys-color-surface-variant` | custom `.bg-surface-variant` |
| `text-muted-foreground` | `--md-sys-color-on-surface-variant` | custom `.text-on-surface-variant` |
| `border-border` | `--md-sys-color-outline` | `.border` |
| `bg-background` | `--md-sys-color-background` | `body` bg |
| `text-foreground` | `--md-sys-color-on-background` | `body` color |

## 7. Risk Register

| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| Bootstrap + MD3 bundle size larger than Tailwind | High | Medium | Tree-shake MD3 imports; only import needed components |
| jQuery conflicts with Bootstrap JS | Medium | High | Bootstrap 5 uses vanilla JS (no jQuery dependency). Use `bootstrap.native` or configure Bootstrap to not auto-init |
| MD3 Web Components don't work with jQuery | Medium | Medium | MD3 components are self-contained; jQuery can still manipulate DOM around them |
| Mobile nav breaks during migration | High | High | Bootstrap has built-in navbar collapse; replace custom jQuery mobile nav with Bootstrap's |
| Contact form styling breaks | Medium | Medium | Rewrite form classes to Bootstrap form classes; keep jQuery validation logic |
| Showcase filter JS breaks | Low | Medium | jQuery filter logic is independent of CSS framework; should still work |
| Build pipeline breaks | Medium | High | Test `bun run dev` after every config change; keep `tailwind.config.js` until Phase 6 |

## 9. Notes for AI Coding Agents

When migrating Blade files, follow this pattern:

1. **Start with layout** — `layouts/app.blade.php` sets the container/scaffolding
2. **Use Bootstrap classes first** — `container`, `row`, `col-*`, `card`, `btn`, `d-flex`, `align-items-center`, `justify-content-between`
3. **Apply MD3 tokens second** — Use CSS custom properties for colors: `style="color: var(--md-sys-color-primary);"`
4. **Custom classes last** — Only when Bootstrap + MD3 don't have the pattern
5. **Never use Tailwind classes** — If you see `mx-auto`, `max-w-7xl`, `px-6`, `py-20`, `rounded-2xl`, `bg-card`, `text-muted-foreground` — replace them

### Common Tailwind → Bootstrap Mapping

| Tailwind | Bootstrap | Notes |
|----------|-----------|-------|
| `mx-auto` | `mx-auto` (same) | Works in Bootstrap too |
| `max-w-7xl` | `container` | Bootstrap container max-width is 1320px (xl) |
| `px-6` | `px-4` | 1.5rem in both |
| `py-20` | custom `.py-5` or `.section-padding` | Bootstrap only goes to `.py-5` (3rem) |
| `flex` | `d-flex` | |
| `items-center` | `align-items-center` | |
| `justify-between` | `justify-content-between` | |
| `gap-6` | `gap-3` | 1rem in Bootstrap |
| `grid` | `row` + `col-*` | Bootstrap uses row/col, not CSS grid |
| `grid-cols-3` | `row row-cols-1 row-cols-md-3` | |
| `space-y-6` | `vstack gap-4` | Bootstrap 5.1+ has vstack |
| `rounded-2xl` | `rounded-4` or custom | Bootstrap has `.rounded-0` to `.rounded-5` |
| `rounded-full` | `rounded-pill` | |
| `border` | `border` | |
| `border-border` | custom `border-md3` | Use MD3 outline token |
| `bg-card` | `bg-white` or custom | |
| `text-sm` | `fs-6` or `small` | Bootstrap font sizes are semantic |
| `text-xs` | custom `.fs-7` | Bootstrap only goes to `.fs-6` |
| `font-bold` | `fw-bold` | |
| `font-medium` | `fw-medium` | Bootstrap 5.2+ |
| `tracking-tight` | custom | Letter-spacing not in Bootstrap utilities |
| `uppercase` | `text-uppercase` | |
| `text-center` | `text-center` | Same |
| `hidden` | `d-none` | |
| `lg:flex` | `d-none d-lg-flex` | Responsive display |
| `sticky top-0` | `sticky-top` | Bootstrap has sticky-top |
| `z-50` | custom | Bootstrap doesn't have z-index utilities |
| `backdrop-blur-xl` | custom | CSS backdrop-filter |
